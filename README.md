# Boiler (Shopify Theme Starter with Tailwind CSS)

A clean, minimal, zero-bloat Shopify theme setup built from scratch with **Tailwind CSS**.

No predefined components or complex sections are included—this gives you a complete blank canvas to learn and build your custom Shopify theme.

---

## Folder Structure

```
Boiler/
├── assets/
│   └── tailwind.css         # Generated by Tailwind CLI (do not edit directly)
├── config/
│   ├── settings_data.json   # Theme customizer data
│   └── settings_schema.json # Theme customizer settings schema
├── layout/
│   └── theme.liquid         # Minimal HTML shell loading tailwind.css
├── locales/
│   └── en.default.json      # Translation strings
├── sections/                # Create your Liquid sections here
├── snippets/                # Create your reusable Liquid snippets here
├── src/
│   └── tailwind.css         # Tailwind source entry point & scan paths
├── templates/
│   └── index.json           # Home page JSON template
├── .gitignore
├── .theme-check.yml
└── package.json
```

---

## How Tailwind CSS Works Here

- **Input File**: [src/tailwind.css](file:///home/asad/Documents/Boiler/src/tailwind.css) imports Tailwind and defines `@source` paths to scan:
  - `layout/**/*.liquid`
  - `sections/**/*.liquid`
  - `snippets/**/*.liquid`
  - `templates/**/*.{liquid,json}`
  - `assets/**/*.{js,liquid}`
- **Compiled Output**: [assets/tailwind.css](file:///home/asad/Documents/Boiler/assets/tailwind.css) is loaded in [layout/theme.liquid](file:///home/asad/Documents/Boiler/layout/theme.liquid) via `{{ 'tailwind.css' | asset_url | stylesheet_tag }}`.

## Available Commands

From the `Boiler/` directory:

| Command | Description |
|---|---|
| `npm run dev` | Runs both Tailwind file watcher and Shopify local dev server concurrently |
| `npm run watch` | Watches for changes in Liquid/JSON files and rebuilds Tailwind CSS |
| `npm run build` | Builds and minifies `assets/tailwind.css` for production |
| `npm run shopify:dev` | Starts local Shopify theme development server |
| `npm run shopify:check` | Validates your Liquid and theme code with Theme Check |
| `npm run shopify:push` | Pushes your local theme files to your Shopify store |
| `npm run shopify:pull` | Pulls theme files from your Shopify store |
